Welcome to build Jurion Online Judge!
    Jurion Online Judge is a Online Judge System for littel server and PCs,it just need a little memories and can link net's.Like raspberry and old linux pc.If you are using windows.You need to build all for it.
    Jurion Online Judge is default to use cern-httpd.Because it is lite in nearly years.If you want to used modern HTTPd servers.You can edit httpd.conf.

Build it!

    First,If your system is Debain 7 32bit and your CPU is armv6 you can use the shell file. You need use bash to exec it.It will be take your Online Judge System quickly and easy.
    But,if your system is other system you can downlaod src files to build it by yourself.If you cpu is ARM.You can try to run it with out other steps.
    Second,After finish your build.You can edit many files. Like add some css and js.Make it looks beautiful!But you need to note it is from Jurion Online Judge!Cheers!
